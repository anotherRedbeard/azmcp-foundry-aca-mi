# Shared Web Host Infrastructure

This directory contains the Bicep modules shared by the web application
deployment workflows. It is not a deployment guide.

Follow the web application README for the identity model you selected:

- [`managed-identity/agent-web-app/README.md`](../managed-identity/agent-web-app/README.md)
- [`user-passthrough/agent-web-app/README.md`](../user-passthrough/agent-web-app/README.md)

Each application guide contains its own local configuration, validation,
GitHub OIDC, deployment, and post-deployment steps.
